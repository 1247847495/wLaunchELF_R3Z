# ============================================================
# GAMETITLES.TXT —— 自定义游戏中文标题
# ============================================================
# 用途: 补充或修正记忆卡 L1"游戏标题+详细信息"显示模式的中文名。
#       本文件的译名优先于程序内置对照表(可覆盖内置翻译)。
#
# 放置位置(任选其一):
#   1. 记忆卡 mc0:/SYS-CONF/ 或 mc1:/SYS-CONF/ 目录下
#   2. 与本 ELF 程序同一个目录下
#
# 格式: 每行一条 "产品代码=简体中文标题"
#   - 产品代码支持多种写法,以下三行等价:
#       SLUS-20946=侠盗猎车手：圣安地列斯
#       SLUS_209.46=侠盗猎车手：圣安地列斯
#       BASLUS-20946=侠盗猎车手：圣安地列斯
#   - 不知道代码? 在文件浏览器里按 L1 切换回普通文件名显示,
#     存档目录名(如 BASLUS-20946xxxx)里就包含代码。
#   - '#' 或 ';' 开头为注释行,空行忽略
#   - 编码随便存: 记事本默认的 UTF-8、ANSI(GBK)、Unicode 都能识别
#   - 同一代码只写一行;最多2048条;标题最长48个汉字
#   - 修改保存后,重新运行程序生效
#
# 下面是示例行,去掉行首的 # 即可生效:
#SLUS-20946=侠盗猎车手：圣安地列斯
#SCES-50383=合金装备2：自由之子
#SLES-52541=火影忍者：终极忍者2
